# Remaining-control dispatcher — blocked draft

This package is being prepared for the fixed remaining controls only:
15 Stdlib cases (including two analyst alternatives) and 12 AWS cases.
There is no gate binding or runtime freeze, so staging and submission are
unavailable. Original source/control projections are retained while the failed
Stdlib reference designs are deliberately revised in a separate version.

The planned gate requires all four references to pass reviewed source/raw/native
inventory checks, with exact qualified profiles and fixture manifests pinned.
Original controls will not be silently matched to changed contracts or headers.
Root must explicitly select the reviewed current fixture version before this
draft is finalized.

Tool versions, flags and per-invocation caps remain unchanged. The intended
serial jobs use one CPU and 4 GB, with fixed outer job limits of two hours for
Stdlib and four hours for AWS. Omission controls may exclude only their exact
predeclared file subset; helper mutations are analyst trust controls and remain
ineligible for model acceptance. All native raw evidence will be preserved.

No SSH, native or model calls have been made by this draft. The copied reviewer
and new control gate are unfinished and unqualified; do not run this package.
